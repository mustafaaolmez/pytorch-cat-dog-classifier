# 🐱🐶 Kedi ve Köpek Sınıflandırma Projesi

Derin öğrenme tabanlı ikili görüntü sınıflandırma (binary classification) çalışması.

---

## 🎯 Proje Amacı

Bu proje, bilgisayarlı görü alanında kedi ve köpek görüntülerini ayırt edebilen bir derin öğrenme modeli geliştirmeyi amaçlamaktadır. Çalışma, evrişimsel sinir ağları (CNN) ve transfer learning yaklaşımı üzerine odaklanmaktadır.

---

## 📦 Veri Seti

Kullanılan veri seti Kaggle üzerinden temin edilmiştir:

https://www.kaggle.com/datasets/tongpython/cat-and-dog

Veri seti boyutu büyük olduğu için repository içerisinde yer almamaktadır. Notebook, veri setinin kullanıcı tarafından sağlanan dizin yolunda bulunmasına göre çalışacak şekilde yapılandırılmıştır.

---

## 🛠 Kullanılan Yöntemler

- Convolutional Neural Networks (CNN)  
- Transfer Learning  
- ResNet Mimarisi  
- Cross Entropy Loss  
- Adam Optimizer  
- PyTorch Dataset & DataLoader  

---

## 💻 Ortam Bilgisi

- Python 3.10.x  
- PyTorch  
- CPU / CUDA destekli GPU uyumlu  

---

## 🚀 Projeyi Çalıştırma

1. Notebook dosyasını açın  
2. Veri seti dizin yolunu güncelleyin  
3. Hücreleri sırasıyla çalıştırın  

---

## ⚠️ Not

Veri seti repository içerisinde bulunmaz. Kaggle üzerinden indirmeniz gerekir.
